# Abusive Corporate Division as an Institutional-Design Problem

Replication code for the paper

> **Abusive Corporate Division as an Institutional-Design Problem: Deterrence, Classification, and Selective Accommodation in Japan**

This repository contains the Python pipeline used to build the monthly panel, run the
reduced-form count models, and produce the illustrative calibrated simulation and all
robustness checks reported in the paper. The empirical strategy is deliberately modest:
the reduced-form models are statistical estimates, whereas the simulation is an
*illustrative numerical exercise* whose inputs are benchmark parameters rather than
estimates. The code is organized so that every number in Sections 4–5 and Appendices B–D
can be regenerated from the three source data files.

## Requirements

Python 3.10+ and the packages in `requirements.txt`:

```bash
python -m venv .venv && source .venv/bin/activate      # optional
pip install -r requirements.txt
```

Core dependencies: `numpy`, `pandas`, `scipy`, `statsmodels`, `scikit-learn`, `matplotlib`, `patsy`.

## Data

The analysis uses a monthly panel (January 2009 – January 2026) built from three files,
which are **not redistributed** here. Place them in `data/` (or point `ADV_DATA_DIR` to
their location). The expected filenames are:

| File | Content |
|---|---|
| `commercial_registry_monthly_clean_for_simulation.csv` | Cleaned monthly commercial-registry counts (divisions, special liquidations, bankruptcies/civil rehabilitations, reorganizations, incorporations, etc.) |
| `マクロ指標.csv` | Macroeconomic indicators (stock indices, exchange rates, lending rates) |
| `貸出債券市場取引動向_全銀協_.csv` | Loan / bond-market conditions (Japanese Bankers Association) |

See `data/README.md` for the expected columns. Paths and output locations can be
overridden with environment variables:

```bash
export ADV_DATA_DIR=/path/to/data
export ADV_OUTPUT_DIR=/path/to/outputs
```

All randomized steps use a fixed seed (`RANDOM_SEED = 42`), so results are reproducible.

## Usage

Run from the repository root.

### 1. Core pipeline (panel, proxies, calibrated simulation)

```bash
python src/abusive_division_simulation_v2.py
```

Builds the merged monthly panel and latent proxies, fits the Type I model, runs the
calibrated simulation and the ω-sensitivity of the integrated welfare ranking
(§4.3, §5.1, §5.3), and writes tables/figures to `outputs/v2/`.

### 2. Reduced-form robustness (§4.2, §5.2)

```bash
python src/ejle_robustness_checks.py                 # all checks
python src/ejle_robustness_checks.py --only nb       # negative-binomial IRR table (§4.2)
python src/ejle_robustness_checks.py --only event    # event study, pre-trend test (§5.2)
python src/ejle_robustness_checks.py --only counterfactual   # forecast counterfactual (§5.2)
python src/ejle_robustness_checks.py --data-dir /path/to/data
```

Outputs to `outputs/robustness/` (IRR table, event-study coefficients, reform
counterfactual paths).

### 3. Additional robustness (Appendix D, Appendix B.6)

```bash
python src/ejle_additional_robustness.py --part all
python src/ejle_additional_robustness.py --part 1    # alternative outcomes (Appendix D.1)
python src/ejle_additional_robustness.py --part 3    # trend-form robustness (Appendix D.2)
python src/ejle_additional_robustness.py --part 2 --n2 70   # period-constant sensitivity (Appendix B.6)
```

Outputs to `outputs/additional_robustness/`:
`out_part1_irr.csv`, `out_part1_counterfactual.csv`, `out_part2_period.csv`, `out_part3_trend.csv`.

- **Part 1** re-estimates the §4.2 count model with special liquidation, bankruptcy/civil
  rehabilitation, and the two combined as the outcome; the positive associations are
  specific to special liquidation.
- **Part 2** sets all period calibration constants to zero (placebo) and perturbs them, to
  show the 2012–2015 pattern is generated by the proxies, not the constants.
- **Part 3** re-estimates with linear, quadratic, and natural-cubic-spline trends; the
  post-2019 association is statistically clear only under a linear trend.

### 4. Weight-sensitivity (Appendix C)

```bash
python src/weight_sensitivity.py 100 0.25     # 100 draws, ±25% perturbation
python src/weight_sensitivity.py 100 0.40     # ±40% stress test
```

Perturbs the Appendix C construct weights, rebuilds the latent proxies, and re-simulates
under a fixed simulation seed (only the weights vary). Writes
`outputs/weight_sensitivity/weight_sensitivity_runs.csv` and prints the stability of the
abuse rate and the success gradients.

## Mapping of scripts to the paper

| Script | Paper sections |
|---|---|
| `abusive_division_simulation_v2.py` | §3 proxies; §4.3 illustrative simulation; §5.1 policy scenarios; §5.3 calibration; ω-sensitivity |
| `ejle_robustness_checks.py` | §4.2 negative-binomial IRR; §5.2 event study and forecast counterfactual |
| `ejle_additional_robustness.py` | §4.2 / §5.2 / Appendix D (outcomes, trend forms) and Appendix B.6 (period constants) |
| `weight_sensitivity.py` | Appendix C (construct-weight sensitivity) |

## Notes

- The simulation is an illustrative numerical exercise, not a structural estimation; its
  coefficients and the construct weights are benchmark parameters, not estimates.
- The reduced-form intervals are model-based and do not adjust for residual serial
  correlation; an HAC adjustment would widen them and reinforce the inconclusive readings.
